Set up once (about 10 minutes, free)

  1. Open Google Cloud Console and create a project with any name.
  2. Open the API Library, search for Google Photos Picker API, and click Enable.
  3. Open the OAuth consent screen. Choose External, enter an app name and your email, add the scope ending in photospicker.mediaitems.readonly, and add your own Google email under Test users.
  4. Open Credentials, click Create credentials, choose OAuth client ID, and pick Web application.
  5. Under Authorized JavaScript origins, add this address:
  6. Click Create, copy the Client ID, paste it below, and click Save and continue.

Connect your Google Photos

What will I see?
  1. A Google sign-in window. Use the account you added as a Test user.
  2. If Google says "Google hasn't verified this app", click Advanced, then Go to app. This is normal for your own test app.
  3. Google's photo picker opens with your real library. Select photos and click Done.
  4. Come back to this tab. Yaad reads each photo, about one every 7 seconds.
Google says “Access blocked” or “invalid_request”? Open this page from your https vercel.app address in Chrome, check that the same address is under Authorized JavaScript origins (no trailing slash, client type Web application), add the photospicker scope under Data Access, and wait a few minutes.
If nothing opens, allow pop-ups for this site. Change Client ID
